## Repositorio remoto

Este contenido fue incorporado desde GitHub.
¿Qué es Git?
un repositorio local

¿Qué es GitHub?
un repositorio remoto

¿Qué diferencia existe entre un repositorio local y uno remoto?
que uno local permanece en el equipo de alguien y el remoto en internet si es publico

¿Qué hace git commit?
hace que registra y fija los cambio a nivel local

¿Qué hace git push?
sube los cambio ya "guardados" al repo remoto

¿Qué hace git pull?
trae los cambios que estan guardados en el repo remoto

¿Qué significa origin?
es el nombre que usamos para utilizar el repo remoto
